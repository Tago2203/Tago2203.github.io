Política de privacidade: Boletos Gmail (uso pessoal)

O que o app acessa: só leitura dos e-mails (permissão "Ver seus e-mails") da conta da própria dona, para achar boletos, guias e faturas.

Onde os dados ficam: só no computador da dona. A chave de acesso fica criptografada pelo próprio Windows.

Com quem compartilha: com ninguém. Os dados não são vendidos, enviados a terceiros, usados para publicidade nem para treinar inteligência artificial.

O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como desligar: remova o acesso em myaccount.google.com/permissions.
